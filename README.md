# Survey Feedback Analyzer

## Project Introduction
This project analyzes customer feedback using Python.

## Objectives
- Add new feedback entries
- Clean feedback text
- Count specific words in feedback
- Calculate the average rating
- Find the longest feedback comment
- Display unique words without duplicates

## Tools Used
- Python
- Jupyter Notebook

## Key Findings
- Total feedback entries: 15
- Average rating: 3.67 out of 5
- Feedbacks containing "good": 4
- Feedbacks containing "poor": 3
- Feedbacks containing "excellent": 2
- Longest feedback: "poor response and poor handling of issue"

## Conclusion
This project demonstrates basic Python skills for cleaning and analyzing customer feedback. The results help identify customer satisfaction levels and areas that may need improvement.
